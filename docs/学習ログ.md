### MVP でできること

```
案件掲載 → 応募 → オファー → 承諾（ダブルオプトイン）→ 契約が自動生成
  → 稼働報告を週次で提出 → 承認/差し戻し → 検収して完了 → 相互レビュー同時公開
```

信頼の設計・4本柱のうち **3つが完成**（連絡先マスキング／稼働報告／レビュー同時公開）。
残るエスクロー決済は M4。
