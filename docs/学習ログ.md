## Before との対比で覚えておくこと（このリポジトリの核）

- **一次情報の場所が変わった**: Before は手書きコードが正。After は `.tsp`（API契約）と `queries/*.sql`＋`migrations/`（DB）が正で、Go/TS は生成物。直すのは常に一次情報側
- **層の責務**: handler=生成IFの実装・詰め替えのみ／usecase=業務ロジック・Tx境界／`shared/domain`=遷移表・不変条件（DBにもHTTPにも依存しない）。repository 層は作らない（sqlc の `Queries` が相当）
- **規約は仕組みで強制**: 依存方向は depguard / ESLint、認証要否は仕様の `@useAuth` から起動時に導出、生成物の鮮度は CI の差分チェック。「気をつける」を「破れない」に変える
- **テストはモックしない**: 実DB＋pgx.Tx 分離＋factories（ADR-0008）。SQL・制約・型の詰め替えまで含めて保証する
