# ADR-0010: テーマ変更を機に視覚回帰を再判断し、導入見送りを継続する

- ステータス: Accepted（承認済み）
- 日付: 2026-08-18

## 背景

[ADR-0009](0009-defer-visual-regression.md) は視覚回帰の導入を見送り、再検討の発動条件を定めた。
#71（ブランドトークンの整理）で **発動条件1「shadcn 部品のカスタマイズやテーマ変更を始めるとき」が発火**したため、
決めたとおり再判断を行う。

## 決定

視覚回帰の**導入見送りを継続**する。あわせて発動条件を実態に合わせて絞り直す:

1. ~~テーマ変更を始めるとき~~ → **部品単位のスタイル改変で意図しない波及が出たとき**（UI-3 カード化以降が該当しうる）
2. UI の意図しない差分事故が実際に起きたとき（変更なし）
3. デザイン調整 PR のレビューが目視で追えない規模になったとき（変更なし）

## 代替案と却下理由

| 案                              | 却下理由                                                                                                                                                                                                                 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 発動条件どおり Chromatic を導入 | 今回の変更は「トークン値の一括調整」で、差分が**全部品に一様**に現れる性質。Storybook の全 story 流し見（20+ story・数分）で十分レビューでき、ピクセル比較が検出する「意図しない局所差分」がそもそも発生しない構造だった |
| 条件を消して恒久見送り          | 部品単位の改変（カード化・variant 追加）では局所差分が発生しうる。条件は残す                                                                                                                                             |

## 影響

- 発動条件1が「テーマ変更」から「部品単位の改変での波及」に置き換わり、次の再判断ポイントは UI-3（#72）以降
- 学び: **発動条件は「イベント」でなく「差分の性質」で書くべき**だった。テーマ変更というイベントは起きたが、
  そこで生じる差分は一括・一様で視覚回帰の得意領域ではなかった。条件設計の教訓として記録する
- ADR-0009 は不変のまま（本 ADR が判断の追記。Superseded ではない — 0009 の決定「導入しない」は継続している）
