# デザインシステム — Tsunagu Works

> 決定日: 2026-08-03（Issue #7 着手時）。全画面はこのドキュメントに従う。
> 出典: 仕様デッキのブランド色 ＋ ui-ux-pro-max スキルの推奨（B2B SaaS / マーケットプレイス / 信頼訴求）を統合。

## コンセプト

**「信頼の設計」を体現するクリーン・プロフェッショナル**。
過度な装飾・アニメーションを避け、余白とコントラストで整える。ライトモードのみ（ダーク非対応）。

## カラートークン（globals.css の `:root` で定義）

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--primary` | `#1d4ed8`（ブランド青） | 主ボタン・リンク・アクティブ状態 |
| `--primary-foreground` | `#ffffff` | Primary上の文字 |
| `--background` | `#f8fafc`（slate-50） | ページ背景 |
| `--card` | `#ffffff` | カード・パネル背景（背景と分離） |
| `--foreground` | `#0f172a`（slate-900） | 本文文字（コントラスト AA 準拠） |
| `--ring` | `#1d4ed8` | フォーカスリング |
| （予約）青緑 | `#0f766e` | 成功・信頼バッジ（KYC承認等）。使用時にトークン化する |
| `--destructive` | shadcnデフォルト | エラー・破壊的操作 |

- CTA にオレンジ等の別色は使わない（業務画面に別CTA色は過剰。LP作成時に再検討）
- 色だけで意味を伝えない（エラーはアイコン/文言併用）

## コンポーネント方針

- **shadcn/ui（radix・Nova）を標準**。角丸 `--radius: 0.625rem`・影は控えめ、デフォルトから触らない
- shadcn製は `components/ui/`、自作は `components/` 直下
- アイコンは **Lucide** のみ（絵文字をアイコンにしない）

## フォームUX（認証画面から適用）

- ラベルは**常に表示**（placeholderをラベル代わりにしない）
- エラーは**フィールド直下**に表示（色＋文言。色だけにしない）
- 送信中はボタン無効＋ローディング表示（二重送信防止）
- 検証は blur 時（入力中に赤くしない）／送信失敗時は先頭エラーへフォーカス
- `type="email"` 等のセマンティックな input type・`autocomplete` 属性を付ける
- タッチターゲットは 44px 以上（`h-11` 目安）

## アンチパターン（このプロダクトでやらないこと)

- ダークモード対応・`dark:` クラス
- 装飾目的のグラデーション・過度なアニメーション（150–300ms のマイクロインタラクションまで）
- 絵文字アイコン／ページごとに異なるトーン
