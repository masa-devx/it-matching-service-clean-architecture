# デザインシステム — Tsunagu Works

> 決定日: 2026-08-03（Issue #7 着手時）。全画面はこのドキュメントに従う。
> 出典: 仕様デッキのブランド色 ＋ ui-ux-pro-max スキルの推奨（B2B SaaS / マーケットプレイス / 信頼訴求）を統合。

## コンセプト

**「信頼の設計」を体現するクリーン・プロフェッショナル**。
過度な装飾・アニメーションを避け、余白とコントラストで整える。ライトモードのみ（ダーク非対応）。

## スケール（余白・タイポ）

**任意の値を使わず、決まった段階から選ぶ**（モジュラースケール）。値がばらつくと、画面ごとに微妙に違う見た目になり「揃っていない感じ」の原因になる。

### タイポグラフィ

| 用途 | Tailwind | px | 使いどころ |
| --- | --- | --- | --- |
| 補足・注記 | `text-xs` | 12 | ヘルプテキスト・Badge |
| 本文小 | `text-sm` | 14 | 説明文・ラベル・カード内の情報 |
| 本文 | `text-base` | 16 | 入力欄（**モバイルで16px未満はiOSが自動ズームする**） |
| 小見出し | `text-lg` | 18 | セクション見出し |
| ページ見出し | `text-2xl` | 24 | h1（`PageHeader` が担当） |

- ウェイトは 400（本文）/ 500（`font-medium`: ラベル・強調）/ 700（`font-bold`: 見出し）の3段階
- 数値の表示は `tabular-nums`（桁が変わっても幅が揃い、一覧・カードのレイアウトが揺れない）

### 余白（4/8px グリッド）

| Tailwind | px | 使いどころ |
| --- | --- | --- |
| `gap-2` | 8 | 要素内の細かい間隔（Badge同士・アイコンと文字）※**タッチ要素間の最小値** |
| `gap-3` | 12 | 一覧アイテム間 |
| `gap-4` | 16 | カード内のブロック間・フォームのフィールド内 |
| `gap-6` | 24 | **セクション間**（ページ内の標準的な区切り） |
| `gap-8` | 32 | 大きな区切り（ヘッダー内のロゴとナビなど） |

- ページの縦構造は `flex flex-col gap-6` を基本とする
- カード内側の padding は `p-4`（16px）

## コンポーネント方針

- **shadcn/ui（radix・Nova）を標準**。角丸 `--radius: 0.625rem`・影は控えめ、デフォルトから触らない
- shadcn製は `components/ui/`、自作は `components/` 直下（ロール専用は `company/` `talent/`）
- アイコンは **Lucide** のみ（絵文字をアイコンにしない: 環境依存で見た目が変わる・CSSで制御できない・スクリーンリーダーが意図しない読み上げをする）
- **装飾のアイコンは `aria-hidden="true"`／アイコンのみのボタンは `aria-label`**（意味を持つか装飾かで扱いを変える）

### 共通レイアウト部品（自作）

| 部品 | 役割 | 使う場面 |
| --- | --- | --- |
| `PageHeader` | 見出し＋説明＋右側アクション | **全ページの先頭**（h1 はここに集約し、階層管理を1か所に） |
| `EmptyState` | アイコン＋説明＋次の行動 | 一覧が0件のとき。**「何も無い」で終わらせず導線を置く**（icon を必須プロパティにして強制） |
| `StatCard` | ラベル＋数値 | ダッシュボードの指標 |
| `Pagination` | ページ送り | 一覧（ページ番号はURLに持つ） |

### 導入済みの shadcn/ui 部品

`button` / `card` / `input` / `label` / `textarea` / `select` / `badge` / `separator` / `skeleton` / `sonner`

- **生の `<select>` を使わない**: shadcn（Radix）の Select はキーボード操作・aria・フォーカス管理が組み込み済み。RHF とは `Controller` で繋ぐ（`register` は DOM 要素前提のため使えない）
- **タグ的な表示は Badge**（自前の `<span className="rounded-full...">` を書かない）
- トーストは `sonner`。描画先の `<Toaster />` はルートレイアウトに1つ

## フォームUX（認証画面から適用）

- ラベルは**常に表示**（placeholderをラベル代わりにしない）
- エラーは**フィールド直下**に表示（色＋文言。色だけにしない）
- 送信中はボタン無効＋ローディング表示（二重送信防止）
- 検証は blur 時（入力中に赤くしない）／送信失敗時は先頭エラーへフォーカス
- `type="email"` 等のセマンティックな input type・`autocomplete` 属性を付ける
- タッチターゲットは 44px 以上（`h-11` 目安）

| 画面系統 | パターン |
| --- | --- |
| 認証（(guest)） | 中央寄せ単一カード・ロゴ→フォーム→切替リンクの縦一列 |

## アンチパターン（このプロダクトでやらないこと)

- ダークモード対応・`dark:` クラス
- 装飾目的のグラデーション・過度なアニメーション（150–300ms のマイクロインタラクションまで）
- 絵文字アイコン／ページごとに異なるトーン
